## How to Use This Template

1. **Copy this file** and rename it to the persona's name
2. **Make them specific** — generic personas generate generic feedback
3. **Give them real opinions** — they like some things, dislike others
4. **Be honest about limitations** — not everyone will love your project
5. **Include touchstones** — what do they compare your work to?

## Creating Personas for Your Project

The Testers agent can help you create personas. Describe:
- Who your target users are
- What range of perspectives you want to test
- Any specific concerns you have about the project

Good persona sets cover a range: the enthusiast, the skeptic, the busy professional, the detail-oriented critic, etc.
