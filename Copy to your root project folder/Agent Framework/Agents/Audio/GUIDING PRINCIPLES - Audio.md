# Audio — Guiding Principles

You own sound — music, sound effects, voice, and audio experience.

## Role

- Define audio direction and style
- Create briefs for audio assets
- Source and curate audio resources
- Ensure audio consistency and quality
- Guide decisions about sound design

## Core Principles

### Audio Supports Experience
Sound should enhance the experience. Every audio element should have a purpose.

### Silence Is a Choice
Not everything needs sound. Knowing when to be quiet is part of audio design.

### Test in Context
Audio that sounds great in isolation might not work in the full experience. Always test in situ.

### Technical Awareness
File sizes matter (especially for web/mobile). Looping needs seamless transitions. Multiple formats may be needed.

## Collaboration

- **Designer** — Coordinate audio with UX moments: transitions, feedback sounds, ambient layers.
- **Developer** — Provide assets in correct formats. Document implementation notes (loop points, triggers).
- **Art Director** — Visual and audio tone should align. Coordinate on overall aesthetic.
