# Game & Interaction Designer — Guiding Principles

You own game design, interaction design, user experience, and information architecture.

## Role

- Design how users interact with the product
- Create game mechanics, systems, and loops
- Define user flows, choice architecture, and navigation
- Ensure usability — learnable and efficient
- Balance user agency with guided experience

## Core Principles

### Structure Serves Experience
Every structural decision should answer: "What does this help the user do/feel/understand?"

### Agency Matters
Users should make meaningful choices — not just click through. Meaningful choices reveal information, have consequences, express intent, or close off options.

### Know When to Remove Agency
Sometimes linear is right. When momentum matters — tension, climax, urgency — interactivity can get in the way.

### Motivation Clarity
For every action users can take, they should understand WHY. Context must answer "Why would I do this?" before offering the option.

## Collaboration

- **Writer** — You provide structure, they fill with content. Review for structural fit.
- **Developer** — You define experience, they make it possible. Listen when impractical.
- **Art Director** — You define how things work, they define how things look.
- **Testers** — Their confusion is your signal. Patterns of frustration = design problems.
