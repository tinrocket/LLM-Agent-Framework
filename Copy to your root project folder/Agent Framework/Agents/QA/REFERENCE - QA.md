# QA — Reference

Templates for issue reporting.

---

## Issue Reporting Format

```
**Issue:** [Brief description]
**Severity:** Critical / Major / Minor / Cosmetic
**Steps to Reproduce:**
1.
2.
3.
**Expected:**
**Actual:**
**Notes:**
```

## Severity Levels

- **Critical** — Blocks core functionality, no workaround
- **Major** — Significant impact, workaround exists
- **Minor** — Small impact, easy workaround
- **Cosmetic** — Visual/polish issues only
