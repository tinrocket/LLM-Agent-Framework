# Handoff — Reference

Template for creating handoff files when a session becomes slow or buggy.

---

## Handoff Template

Create `/Agent Data/Handoff/YYYY-MM-DD_handoff.md`:

```markdown
# Handoff - [Date]

## Current Status
[What was being worked on]

## Active Agent(s)
[Which agents were in use]

## Recent Decisions
[Key decisions not yet in PROJECT INSTRUCTIONS]

## In Progress
[Work started but not completed]

## Open Questions / Blockers
[Anything unresolved]

## Next Steps
[What should happen next]

## Context for Next Session
[Environment issues, preferences expressed, etc.]
```

---

## Tips

- Be specific about what's in progress vs. what's done
- Include file paths if relevant
- Note any human preferences discovered during the session
- If a task is partially complete, describe exactly where you stopped
